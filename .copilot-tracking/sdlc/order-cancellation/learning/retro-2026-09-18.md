## Evidence Summary

* Gates: design approved (re-approved once after the ADR amendment that collapsed Forbidden into 404), plan approved (re-approved once for the same amendment), pr approved, release approved. No rejections. No approval conditions were recorded on any gate; conditions were carried as approval notes instead.
* Gate records at release: design and pr verify clean from a fresh clone; the plan record reads `stale` because the plan received completion marks after approval ([plan.json](../gates/plan.json), [manifest-1.0.0.json](../release/manifest-1.0.0.json) still reports it `approved` because the installed manifest builder reads the decision without re-hashing).
* Phase validations ([reviews/rpi](../../../reviews/rpi/)): P01, P03, P06, P07 passed first time; P02, P05, P08 were `Revise` then `Pass` after remediation. Independent validation caught a compile error in a project the implementer could not build (P02), a metrics design that counted before commit and counted caller cancellations as failures (P05), and a latent event-type resolution bug that only surfaced under the functional-test host (P08). A P06 test failed on first execution because it had never been run; a P07 interaction was dead under static server rendering.
* Code review ([review.md](../../../reviews/code-reviews/order-cancellation/review.md)): Approve with two conditions. RV-001 (functional tests never executed locally) was satisfied by CI run 35306663501 (16/16). RV-003 (ADR still `proposed`) was carried as a note because the ADR bytes are bound into the design approval. RV-002 and RV-005 (low) remain open.
* Test evidence ([tests-2026-09-17.md](../evidence/tests-2026-09-17.md)): 101 tests run, 101 passed across four suites once CI executed the functional suite. Gaps: REQ-002 unauthenticated path has no executed test; REQ-005 asserted at the outbox row, not bus delivery; REQ-009 `succeeded` counts before the transaction commits.
* Requirement trace ([trace-2026-09-18.md](../evidence/trace-2026-09-18.md)): all nine requirements `traced`, no orphans.
* Security ([security-2026-09-18.md](../evidence/security-2026-09-18.md)): CodeQL 0 blocking. The first pr-gate CI run failed on repository baseline hygiene unrelated to the change: two gitleaks hits (a committed developer signing key and a demo token) and nine checkov findings (three missing workflow `permissions`, six on generated OpenAPI documents). Fixed in a separate hygiene pull request; the OpenAPI findings are under a governed 90-day suppression.
* Overlay defects found by the pilot, fixed in this repository's copies only: gitleaks fingerprints carried a `/repo/` prefix so `.gitleaksignore` never matched; the gate workflow always passed `--require-approval` on pull requests because an empty string is falsy in Actions expressions; the SARIF triage wrote a local user path into the evidence file; the .NET template's `[Rr]elease/` ignore rule hid the release manifests from git.
* Audit store (`session-audit metrics`, by stage and agent): 7 sessions recorded (intake 1, architecture 1, plan 1, implement 1, verify 2, release 1), all completed. The eight headless implementation runs and the validator runs did not open sessions, so implement-stage effort is under-recorded. Rework hotspot: `state.json` updated 5 times.

## What Worked

* Human gates with hashed evidence held: every approval was verified from a fresh clone, and the two re-approvals after the ADR amendment were forced by the hash check rather than remembered.
* Phase-by-phase implementation with an independent validator between phases caught three defect classes the implementer reported as done (unbuildable project, unrun test, dead interaction) and one that only CI could expose (entry-assembly event resolution).
* The pr gate's CI scan surfaced real repository hygiene debt on a fork of a well-known sample, and the governed suppression path handled the pre-existing findings without weakening the policy.
* Release evidence was complete on the first build: manifest `complete: true`, all requirements traced, rollback reviewed, verify intact from the tag.
